## Evaluation and implementation

The former five-stage interface mixed motion studies with final excerpts and compressed all post-production into a film link. It omitted explicit keyframe preparation, take review, editing and sound. The replacement uses nine decisions in three phases:

| Phase | Steps | Output |
| --- | --- | --- |
| Pre-production | Story; visual references; storyboard/shot plan | Brief, script, visual guide, ordered shots |
| AI production | Shot frames; motion; review/retakes | Selected frames, candidate clips, accepted ranges |
| Post-production | Edit; sound; finish/publish | Picture edit, sound mix, reviewed deliverable |

The sequence is an educational overview, not a claim of a rigid chronological history for each existing film. Sound can begin early. Review can return to references, frames or prompts. Animatics, 3D blocking, compositing, graphics and VFX are optional techniques, not mandatory separate departments. For image-to-video, references/frame generation can combine modelling/material/lighting/render tasks; manual 3D and rigs remain useful for precise control.

## Illustrated journey interaction

The diagram now uses three horizontal production lanes with nine illustrated nodes, adapting to a vertical journey on mobile. Real screenplay excerpts, character sheets, storyboard panels and film posters provide project-specific thumbnails. Editing, sound and review schematics are explicitly labelled as method illustrations, not screenshots of the actual production timeline or approved take records.

Each node opens a native modal dialog with method, output, review criteria and available project evidence. Previous/next navigation explores the sequence. Multi-image references/storyboards have selectable thumbnails. Closing the dialog unmounts players, Escape works natively and focus returns to the triggering node. Reduced motion disables hover movement. Browser checks covered Vietnamese/mobile, English/desktop, source frame selection, playback cleanup and Titus's evidence gaps.
