# Leo and Mio wordmark

The GenYZ Studio header and footer pair live, theme-aware text with a transparent mascot symbol of Leo and Mio. The website name and accessible home-link label are unchanged. The decorative character image has empty alt text to avoid repeating the link name.

Generated with the built-in imagegen tool using the approved `../Clever Little Rat/characters/leo-character-sheet.png` and `mio-character-sheet.png` references. The original project sheets remain unchanged. Direction: friendly shoulder-to-shoulder portraits, Leo in his yellow shirt, Mio with white fur and floppy ears, transparent background, no generated lettering.

Master: `public/images/brand/leo-mio-master.png`. Web delivery: 320px-wide alpha-preserving WebP at `public/images/brand/leo-mio.webp`. Text remains HTML for legibility at small sizes and in light/dark themes.
